# Unlocking Data Value in Finance: A Study on Distillation and Difficulty-Aware Training

这篇论文与其说是在提出一个全新的金融模型，不如说是在回答一个更根本的问题：金融垂域模型的上限，究竟更多由模型规模决定，还是由后训练数据的质量、难度和可验证性决定。作者的核心观点非常鲜明，认为在金融这种高术语密度、强事实约束、低容错的垂直领域里，后训练数据的构成往往比简单扩大模型规模更关键。

论文摘要可以概括为：虽然通用大模型能力很强，但在金融场景部署时仍会受到专业术语密度高、数值推理严格和事实错误容忍度低等问题的限制。作者通过一组控制实验说明，金融垂域表现很大程度上取决于后训练数据的质量，以及这些数据在难度和可验证性上的分布。为此，论文系统研究了蒸馏数据构建与难度感知训练，并公开了适用于 SFT 与 RL 的金融数据集。

在数据集层面，这篇工作公开了 `ODA-Fin-SFT-318k` 和 `ODA-Fin-RL-12k` 两类数据资源。前者更适合用于监督微调，强调规模与覆盖度；后者则更适合做强化学习，强调可验证性和高价值样本。与许多只关注数据总量的工作不同，这篇论文更强调“什么样的数据应该进入哪个训练阶段”，以及样本难度如何影响最终模型的泛化能力。这种视角对于 FinQA 十分契合，因为 FinQA 本身就具备高可验证、强结构化的特征，天然适合作为难度感知课程中的关键组成部分。

算法和训练框架上，论文主张把蒸馏和难度组织结合起来，而不是先随意蒸馏、再统一训练。其核心思路是先从强教师模型中蒸馏高质量金融样本，再根据任务难度、步骤长度、答案可验证性或错误风险对样本进行再组织，从而在 SFT 和 RL 阶段分别喂给模型不同类型的数据。这样的 pipeline 能减少金融任务中常见的表面拟合问题，也能避免模型在简单样本上过度自信、在复杂样本上不稳定的现象。

实验层面，论文的重点并不是展示单个 benchmark 的极端高分，而是说明数据组织策略对金融垂域整体表现的影响。其结论对于 FinQA 非常重要，因为这意味着即使底座模型相同，只要高质量蒸馏样本和难度分层做得更合理，模型也可能在 FinQA、长文档理解和复杂金融问答上同时取得更稳定的收益。换言之，这篇论文把“数据价值”从辅助因素提升到了训练主轴。

公开页面中没有明确给出完整的 GitHub 仓库，重点更多放在论文与 Hugging Face 数据集上。因此，如果需要复用这篇工作的思想，重点不在代码照搬，而在方法迁移，也就是如何设计金融蒸馏数据、如何区分 SFT 数据与 RL 数据，以及如何建立难度感知的数据采样机制。

对 FinQA 的直接启发非常强。FinQA 可以被视为高价值核心样本，用来承担课程训练中“中高难度、强可验证”的部分，而较容易的金融指令数据可以承担领域语言适配和格式学习。进一步说，FinQA 还可以根据程序长度、证据跨度、表文交互复杂度和答案稳定性重新切出难度层级，用于构造更细粒度的训练 curriculum。这样的复用方式比简单扩大 FinQA 采样比例更可能带来真实收益。
