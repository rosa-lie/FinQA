# 探索机制的几类主流方法

为了提升 RLVR 的训练效果，近期研究提出了多种方法来保持或增强模型的探索能力。
这些方法的核心目标是**缓解训练过程中探索空间的收缩问题——这一现象通常表现为策略熵下降或 Pass@k 指标的退化**。

我们将现有探索增强方法归纳为以下五类：
1. **优势函数优化**
	- 通过调整 RL 中的优势项，使高熵/探索性强的推理路径获得更多奖励，从而鼓励模型持续探索多样解。代表方法包括：Entropy Advantage、Pass@k Training、Negative Sample Reinforcement
2. **Token/梯度选择**
	 - 在 token 层面控制梯度更新，保留具有高探索价值的 token，避免模型过早收敛于低熵策略。代表方法包括：Clip-Higher、Forking Tokens、QeRL
3. **KL 正则化**
	- 通过与参考策略的 KL 距离约束，防止策略漂移过快，同时维持训练稳定性与探索能力。代表方法包括：KL Reference Reset、Covariance-aware KL Penalty
4. **任务结构增强**
	- 通过引入外部工具（如代码执行器）或构建递归任务结构，拓展模型的推理空间，使其能够探索文本生成之外的解法路径。代表方法包括：ECIR、ARPO、ExIt
5. **推理路径多样性增强**
	- 通过奖励结构设计、结果分布控制或任务生成机制，提升模型在推理空间中的覆盖能力，鼓励生成多样化的解法路径。代表方法包括：SvS、DARLING、Outcome-based Exploration、FlowRL

这些方法的共同目标是：防止探索空间塌缩，维持策略多样性，从而为 RLVR 提供更强的推理能力支撑。探索能力的保持不仅是训练稳定性的保障，更是最终性能提升的基础。以下是每篇论文的单独介绍。

## 优势函数优化

### Reasoning with Exploration: An Entropy Perspective
https://arxiv.org/abs/2506.14758

在强化学习（RL）中，如何在**探索（exploration）与利用（exploitation）之间取得平衡**一直是核心问题。尽管近年来在提升大语言模型（LLM）推理能力方面取得了显著进展，但多数方法偏向于利用，导致性能逐渐进入平台期。

本文重新审视了**熵（entropy）作为探索信号**在 LLM 推理中的作用。通过实证分析，作者发现高熵区域与三类探索性推理行为呈正相关：
1. **关键性 token**：决定或连接逻辑步骤的关键词；
2. **反思性行为**：如自我验证与纠错；
3. **罕见行为**：基础模型较少探索的推理路径。
    
基于这一发现，作者提出了一种极简的改进方法：在 RL 的优势函数中加入一个基于熵的项，仅需一行代码即可实现。不同于传统最大熵方法鼓励不确定性，该方法通过鼓励**更长、更深的推理链条**来提升探索能力。

实验结果显示，该方法在 Pass@K 指标上取得了显著提升，尤其在极大 K 值下依然有效，**显著拓展了 LLM 的推理边界**。

### Pass@k Training for Adaptively Balancing Exploration and Exploitation of Large Reasoning Models
https://arxiv.org/abs/2508.10751

传统的 RLVR 方法通常使用 Pass@1 作为奖励指标，这种设计虽然能快速收敛，但也容易导致模型采取保守策略，陷入局部最优，**探索能力受到限制**。作者指出，**奖励设计本身就影响探索与利用的平衡**，而 Pass@k 虽然常用于评估，却很少被用于训练奖励。

为此，作者提出将 **Pass@k 直接作为训练奖励**，并观察到模型的探索能力显著提升。进一步，他们推导出了 Pass@k 的优势函数解析形式，使训练过程更高效、更稳定。

更重要的是，作者发现：**探索与利用并非天然冲突**，合理设计优势函数可以让两者相互促进。这为 RLVR 的未来发展提供了一个新方向——**通过优势函数设计来引导探索行为**，而不仅仅依赖熵或随机性。

这项工作强调了一个关键观点：**探索能力的提升不只是策略层面的调整，更可以从奖励机制本身入手**，尤其是在 LLM 推理任务中，合理的奖励设计可能是突破性能瓶颈的关键。

### From Trial-and-Error to Improvement: A Systematic Analysis of LLM Exploration Mechanisms in RLVR
https://arxiv.org/abs/2508.07534

虽然 RLVR 已被广泛用于提升大语言模型（LLM）的推理能力，但其成功背后一个关键却常被忽略：**探索机制的有效性**。RLVR 的训练过程依赖规则反馈来引导模型生成复杂的推理链条，而这一过程能否成功，很大程度上取决于模型是否具备足够的探索能力。

这篇报告试图填补这一空白，围绕探索机制展开了系统性分析，主要包括三个方面：
1. **探索空间建模**：通过定量指标刻画模型的能力边界，明确模型在哪些区域具备探索潜力，在哪些区域容易陷入局部最优。
2. **熵与性能的关系**：分析训练过程中熵的变化如何影响模型性能，不仅在整体训练阶段，也在具体样本和 token 层面展开细致观察。
3. **探索收益转化机制**：研究如何将探索带来的潜力转化为实际性能提升，避免“探索有了但没用上”的情况。

这项工作不仅整合了已有的经验，还引入了新的实证证据，**试图构建一个关于探索机制的基础框架**，为未来 RLVR 系统的设计与优化提供理论支撑。

### The Surprising Effectiveness of Negative Reinforcement in LLM Reasoning
https://arxiv.org/abs/2506.01347

传统的 RLVR 方法通常通过策略梯度同时强化正确答案、惩罚错误答案。然而这篇工作提出：**即使完全不强化正确答案，仅靠惩罚错误，也能显著提升模型性能，甚至超过主流方法如 PPO 和 GRPO**。

作者将 RL 信号拆解为两个部分：
- **正样本强化（PSR）**：提升正确推理路径的概率；
- **负样本强化（NSR）**：压制错误推理路径，重新分配概率质量。

作者发现在多个数学推理任务上对模型进行训练，发现
- 仅使用 NSR，模型在 **整个 Pass@k 范围内（k 高达 256）** 都表现优异；
- 仅使用 PSR 虽然提升了 Pass@1，但在高 k 值下性能反而下降，说明推理多样性受限。

通过梯度分析，作者进一步揭示了 NSR 的工作机制：它并不是引入新行为，而是**在模型已有知识的基础上进行概率重分配**，压制错误路径，释放探索空间。
基于这一理解，作者提出了一种简单的 RL 变体，**上调 NSR 的权重**，在多个任务上都取得了稳定的性能提升。
这项工作带来的启发是：**探索能力的提升不一定依赖于鼓励“更多尝试”，有时“更有效的排除”也能拓展模型的推理边界**。这为 RLVR 的奖励设计提供了新的思路，也提示我们重新审视“探索”的定义与实现方式。

## Token/梯度选择
### ✅ DAPO: An Open-Source LLM Reinforcement Learning System at Scale
https://arxiv.org/abs/2503.14476

在大模型的强化学习训练中，作者发现传统算法（如 PPO、GRPO）容易出现熵塌缩现象：随着训练推进，模型策略变得高度确定，生成结果趋于一致，探索能力显著下降。

DAPO算法的目标函数在Clip-Higher策略下
将传统PPO/GRPO算法中固定的单一刻度裁剪范围（$1-\varepsilon$至$1+\varepsilon$）
**解耦为独立的下裁剪阈值（$\varepsilon_{\text{low}}$）与上裁剪阈值（$\varepsilon_{\text{high}}$）**
$$\begin{aligned}
\mathcal{J}_{\text{DAPO}}(\theta) &= \mathbb{E}_{(q,a) \sim \mathcal{D}, \{o_i\}_{i=1}^G \sim \pi_{\theta_{\text{old}}}(\cdot \mid q)} \Bigg[ 
\frac{1}{\sum_{i=1}^G |o_i|} \sum_{i=1}^G \sum_{t=1}^{|o_i|} \\
&\quad \min\Bigg( 
r_{i,t}(\theta) \cdot \hat{A}_{i,t}, \ 
\text{clip}\bigg( r_{i,t}(\theta), \ 1-\varepsilon_{\text{low}}, \ 1+\varepsilon_{\text{high}} \bigg) \cdot \hat{A}_{i,t} 
\Bigg) 
\Bigg] \\
\text{s.t.} \quad & 0 < \left| \{ o_i \mid \text{is\_equivalent}(a, o_i) \} \right| < G
\end{aligned}$$

### ✅ Beyond the 80/20 Rule: High-Entropy Minority Tokens Drive Effective Reinforcement Learning for LLM Reasoning
https://arxiv.org/abs/2506.01939
https://mp.weixin.qq.com/s/LAa48HRKNHwBuyBf4TNNRA

作者发现，在长链推理中，只有少数 token 表现出高熵，而这些 token 恰恰是**推理路径中的关键分叉点**，决定了模型是否能走向多样化的解法。
进一步分析 RLVR 训练过程中的熵变化，发现 RLVR 并不会大幅改变基础模型的整体熵分布，而是**主要调整这些高熵 token 的策略**。这说明，RLVR 的有效性很大程度上依赖于对这些“探索性 token”的优化。
基于这一发现，作者提出了一种改进策略：**仅对高熵 token 进行策略梯度更新**。结果显示，这种“少量关键 token 更新”不仅能保持性能，甚至在多个模型上超过了全量更新，展现出强烈的 scaling 趋势。
这项工作表明：**探索机制的核心可能不在于整体策略的多样性，而在于少数关键 token 的决策能力**。通过识别并优化这些高熵 token，RLVR 可以更高效地提升模型的推理能力。

### QeRL: Beyond Efficiency--Quantization-enhanced Reinforcement Learning for LLMs
https://arxiv.org/abs/2510.11696

这篇论文提出了 QeRL，一种结合量化和强化学习的高效训练框架。虽然它的主要目标是提升训练效率，但作者发现一个重要现象：**量化噪声会提升策略熵，从而增强模型的探索能力**。

在 RL 训练中，策略熵代表模型的行为不确定性。
QeRL 中的量化过程引入了随机扰动，使模型在生成过程中更倾向于尝试不同的推理路径。为了进一步利用这一点，作者设计了一个自适应机制，在训练过程中**动态调整噪声强度**，**在关键阶段引导模型进行更积极的探索**。

因此，QeRL 不只是一个效率优化方案，它也提供了一种新的探索机制：**通过系统层面的噪声干预，维持高熵状态，促进策略多样性和推理能力提升**。

## 模型参数更新限制

### ⭕ The Entropy Mechanism of Reinforcement Learning for Reasoning Language Models
https://arxiv.org/abs/2505.22617

作者发现，在不进行熵干预的情况下，RL 训练中的策略熵会在早期迅速下降，导致模型探索能力减弱，性能进入平台期。这种现象在多次实验中反复出现，说明它是**RL 推理任务中的系统性障碍**。
为此，作者建立了一个经验公式将策略熵与下游性能关联起来，揭示了一个重要规律：**性能的上限由熵的耗尽决定**，即当熵趋近于零时，性能也达到可预测的瓶颈。
进一步分析表明，熵的变化由 **token 的概率与 logits 变化之间的协方差驱动**，而这种协方差在训练中大多为正，解释了为什么熵会持续下降。

基于这一机制，作者提出了两种简单但有效的策略：
- **Clip-Cov**：对高协方差 token 的更新进行裁剪；
- **KL-Cov**：对这些 token 施加更强的 KL 正则化。

这两种方法都旨在**限制那些主导熵下降的 token 的影响**，从而延缓熵塌缩，维持模型的探索能力。实验结果显示，这些方法显著提升了下游推理性能。

### ProRL: Prolonged Reinforcement Learning Expands Reasoning Boundaries in Large Language Models
https://arxiv.org/abs/2505.24864

作者提出了一个重要问题：**强化学习（RL）是否真正提升了大语言模型的推理能力，还是只是放大了基础模型中已有的高奖励输出？**

为此，他们设计了一个名为 **ProRL** 的训练方法，并通过长时间训练发现：**RL 能够引导模型探索出基础模型无法覆盖的新推理策略**，即使在大量采样下，基础模型也无法生成这些解法。

更进一步，作者发现：**推理边界的扩展与训练时长和基础模型的任务能力密切相关**，说明 RL 并非仅仅是“利用”，而是可以**逐步探索并填充新的解空间**。

这项工作强调了一个关键观点：**持续的 RL 训练具备探索性，能够突破基础模型的推理限制，拓展其能力边界**，为未来的长程 RL 推理研究奠定了基础。
